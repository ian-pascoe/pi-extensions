# Retire pi-adaptive-thinking and pi-byterover

`pi-adaptive-thinking` and `pi-byterover` are removed from the repository, and every published version is deprecated rather than unpublished. Pi's native thinking-level controls replace `pi-adaptive-thinking`; no replacement is provided for `pi-byterover`. This supersedes ADR-0001's decision to retain these two package names for install compatibility: keeping unmaintained packages active costs more than that compatibility, while npm preserves their historical artifacts.
