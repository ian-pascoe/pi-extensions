Advisor now follows Pi's built-in rendering: `advisor_ask` shows a lowercase `advisor_ask` header, a ten-line Markdown answer with Pi's expand hint, and an `Elapsed`/`Took` footer. Interventions and status entries use Pi's custom-message box with a coloured severity word (`nit`, `concern`, `blocker`), the footer reads `● advisor on`, warnings are prefixed `Advisor:`, and the `/advisor` menu uses the shared settings menu. Requires Pi 1.1.0 or newer.
