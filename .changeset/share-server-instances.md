Share Server Instances among the Pi sessions in one Pi process, so a main session and its in-process subagents or Advisor sessions no longer each start and load their own copy of every language server. Sessions whose Server Definition resolves to the same command, arguments, environment, `initializationOptions`, `settings`, `lsp.timeouts`, and `maxConcurrentDiagnostics` for the same workspace root lease one process; any difference, such as a project override only one session trusts, still gets its own. A session takes its lease on first use and releases it at shutdown or when it disables the Server Definition, and the process stops when the last lease is released. A crash makes the instance unavailable in every session using it, and `/lsp stop` or `lsp_restart` from any of them stops it for all, each starting it again on next use. `lsp_status` and `/lsp` add `shared with N other sessions` to a running instance other sessions also lease, with a matching `shared_with_sessions` structured field. A server-initiated edit becomes a preview only when one session uses the instance; otherwise it is declined because it cannot be attributed to a session. Server stderr files now live in a private temporary directory per Server Instance, removed when it stops, instead of in the session directory.
