The `todo` tool now renders like Pi's built-ins: a lowercase `todo` header, a 20-row Collapsed View with Pi's Expand Hint, and an `Elapsed`/`Took` footer, keeping the `[ ]`/`[>]`/`[x]` checkboxes. The `pi-todo` widget uses the shared layout, and warning and error notifications carry a `Todo:` prefix. Requires Pi 1.1.0 or newer.
