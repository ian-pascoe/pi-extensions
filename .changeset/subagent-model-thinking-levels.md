Subagent Model References accept a thinking level. `%claude-opus-5-5:high` or `%large:low` adds `thinking_level=<level>` to the link title, but only for levels the model supports. Popup descriptions list each entry's supported levels. Typing `:` after a name lists those levels, and selecting one completes it. Model ids that already end in a colon suffix keep it.
