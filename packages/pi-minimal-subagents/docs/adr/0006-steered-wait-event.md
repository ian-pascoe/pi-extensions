# End `subagent_wait` with a `steered` Wait Event

Pi hands a Queued Steer to an agent only after every tool call in the current batch has returned, so a blocked `subagent_wait` holds back the user's or parent's redirection for as long as the child runs. A wait therefore ends early with a Steer Yield (defined in `pi-utils`, [repository ADR-0009](../../../../docs/adr/0009-steer-yield-signal-in-pi-utils.md)) whenever a Queued Steer is pending for the caller's session, including one present when the wait starts. It returns a new `event: "steered"` Wait Event with the requested turn identity and the same compact progress snapshot as a timeout.

Like a timeout under [ADR-0001](0001-wait-event-delivery-ordering.md), a steered wait removes only its waiter: it claims nothing, does not cancel the child, and leaves later Coordination Messages and the terminal result to automatic fallback or a later wait. Reusing `event: "timeout"` would hide why the wait ended, and `event: "message"` already names a Coordination Message. The Queued Steers that count include a parent's Coordination Message queued into a busy Child Agent and another child's result that automatic fallback steers into the parent, so one child's result ends a wait on its sibling.
