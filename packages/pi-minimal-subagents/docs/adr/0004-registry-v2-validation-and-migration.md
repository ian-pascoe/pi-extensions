# Write Registry V2 and migrate Registry V1 at replay

Root-session JSONL is a serialized trust boundary. Minimal Subagents writes Registry V2 envelopes and parses every persisted required and optional field before state reaches the coordinator. Checkpoints additionally validate canonical agent hierarchy, live/tombstone separation, selected leaves for every available agent, ordinary-tool ceilings with coordinator-tool exclusion, result and delivery identity, positive safe and globally unique sequences, monotonic `next_delivery_sequence`, direct-parent terminal destinations, adjacent Coordination Message endpoints, stable message delivery IDs, and source-turn ownership. Unavailable recovery placeholders are the only V2 agents allowed without a selected leaf.

Replay accepts Registry V1 and V2. Valid V1 events are translated into the V2 application representation. Legacy terminal items without a sequence receive deterministic monotonic sequences, and legacy activity events use their envelope timestamp as `recorded_at`. V1 fields that were never durable cannot be reconstructed. All new activity writes carry an explicit clock-injected `recorded_at`; replay never substitutes insertion time for a V2 activity record.

Invalid owned records do not throw or disable the extension. Replay emits semantic diagnostics containing the active-branch entry index, a stable reason code, and a concise explanation. Invalid checkpoints are skipped so replay can fall back to the latest valid checkpoint. Records owned by another Root Agent remain silently out of scope.

The V2 checkpoint stores the pure Delivery Ledger representation in full, including empty Coordination Message and claim collections plus the next sequence. Event updates preserve an existing item's sequence. New delivery sequences are globally unique and strictly increasing across both delivery kinds, while gaps remain valid when malformed records were skipped. Claims identify active, latest, or retained turns, and releases identify existing claims.

Deletion events contain canonical, currently live, complete subtrees. Replay removes delivery state and recent-message projections whose source or destination belongs to the deleted subtree, so the next emitted checkpoint remains independently valid. These constraints make corruption distinguishable from ordinary replay and keep V1 migration isolated at the Registry boundary.
