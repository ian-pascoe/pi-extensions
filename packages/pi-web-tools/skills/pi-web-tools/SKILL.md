# Pi Web Tools

1. Confirm `packages/pi-web-tools/src/index.ts` is installed and active, then reload Pi. Finish when both `web_search` and `web_fetch` are available.
2. For a search failure, read the cause after `Unable to search the web for <query>:`. `query is empty` and `invalid parameters` are not setup faults: send a non-empty query. A validation error that names `type` or `livecrawl` as an additional property means those parameters were removed from `web_search`: drop them. `Exa reported an error`, `Parallel reported an error`, and `returned error <code>` carry the Search Provider's own message; fix the request it names. `Exa rate limit reached` means the anonymous free tier is exhausted: set `EXA_API_KEY` (see step 5) and restart Pi. `HTTP 401` or `HTTP 403` means the provider rejected the key: check `EXA_API_KEY` or `PARALLEL_API_KEY` (see step 5) and restart Pi. `HTTP 429` is a rate limit: set the selected provider's key. For `HTTP 5xx`, `network error <CODE>`, or `timed out`, check outbound network access to the selected Exa or Parallel provider; other `HTTP 4xx` is a request the provider rejected. A `: <provider message>` after the status is the provider's own explanation. Read the provider and key section of [`../../README.md`](../../README.md). Finish when one search returns provider text or the cause identifies an external outage.
3. For a fetch failure, read the cause after `Unable to fetch <url>:`. `HTTP 4xx`, `invalid URL`, `unsupported URL scheme`, and `unsupported content type` are not setup faults: fix the URL, or download a binary document such as a PDF and convert it to text locally. For `HTTP 5xx`, `network error <CODE>` (for example `ECONNREFUSED` or `ENOTFOUND`), or `timed out`, check that the URL is reachable from this machine and raise `timeout` (up to 120 seconds) if needed. Read the Web Fetch section of [`../../README.md`](../../README.md). Finish when one request returns the expected final URL and format.
4. For truncated output, read the returned private spill path with Pi's `read` tool. A search ending `[Search results cut at N characters ...]` hit its character budget (6,000 by default); Exa's marker names the shortened results, whose Title and URL are still shown. Repeat it with `contextMaxCharacters` up to 50,000, or `web_fetch` a result's URL. A fetch ending with the continuation note `[Showing lines A-B of T. ... Use offset=N to continue.]` stopped early: call `web_fetch` again with that `offset` (the spill file holds only the requested `offset`/`limit` window). `Offset N is beyond end of content` means `offset` exceeds the line count it names; lower it. Finish when it contains the complete result and the model-visible output remains bounded.
5. For an API-key problem, confirm `EXA_API_KEY` or `PARALLEL_API_KEY` is present in Pi's process environment without printing its value, then restart Pi. Finish when requests work without a key appearing in output, details, errors, or spill files.
