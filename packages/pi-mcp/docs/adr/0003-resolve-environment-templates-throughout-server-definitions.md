# Resolve environment templates throughout Server Definitions

Every string value within a Server Definition accepts `${VAR}` templates resolved from the MCP Host process environment, including commands, arguments, working directories, URLs, headers, environment values, transport names, and OAuth fields. Map keys, numbers, booleans, and `null` are never interpolated; configured environment values do not recursively define variables for other fields; and missing variables invalidate the definition. Resolution permits public configuration to hide endpoints as well as credentials without adding shell-command substitution. Resolved values exist only at runtime. Diagnostics track interpolated values and scrub their resolved forms from SDK and transport errors; CLI and runtime output omit resolved URLs, headers, environment values, bearer tokens, OAuth secrets, and authorization codes while identifying servers and configuration provenance.
