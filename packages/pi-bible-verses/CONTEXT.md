# Bible Verses context

## Glossary

- **Offline Verse Pool** — the statically embedded collection of 291 Bible passages; it is never fetched, regenerated, or loaded from a user setting.
- **Recent Passage Window** — the process-scoped exclusion list of the 20 most recently selected passage IDs.
- **Working Message** — Pi's temporary status text, set at turn start as `${text} — ${reference} (${translation})` and cleared at turn end.
- **Translation Provenance** — the complete source, rights, edition, archive hash, and notice metadata retained for each embedded translation.
