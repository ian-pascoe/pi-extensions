# Own the normal Rollover Tail size; default it to zero

A normal Rollover already carries an agent-written Handoff, a Note Index, and references to retrievable History. Pi's default `keepRecentTokens` of 20,000 adds a raw transcript Tail on top of that. Pi's estimate also counts thinking text, which Anthropic does not replay from earlier turns, so much of the budget can go to reasoning the model never sees again, and the rest is usually tool output the Handoff already summarizes. Codex's experimental context management (`new_context` with its history and notes extensions) keeps no conversation tail at all when it starts a new context window, and relies only on notes and history tools.

Context Management therefore owns one sizing input: `contextManagement.tailTokens` (a nonnegative integer, default 0) replaces `keepRecentTokens` as the budget that Pi's `findCutPoint` uses for a normal Rollover, whether it comes from `context_rollover`, `/rollover`, threshold or manual preparation, or Idle Rollover. A trusted project overrides global settings; an invalid value is ignored for that file, with one warning per session load. This reopens [ADR-0002](0002-let-pi-own-compaction-policy.md)'s "Pi owns recent-history retention" for normal Rollover only. Pi's cut points still decide where the Tail may start, and complete tool-batch validation is unchanged. With 0, Pi's newest cut point keeps only the `context_rollover` call and its result, so the continuing agent loop still sees its own tool result.

An Emergency Rollover keeps Pi's native cutoff from `keepRecentTokens`. Its saved Handoff may be stale or absent, so recent History is its best continuity, and Pi owns overflow retry.

The name `tailTokens` was previously an obsolete key ignored with a warning. It is reused because Tail is the glossary term; a stale value now takes effect instead of warning. Considered and rejected: leaving users to lower Pi's global `keepRecentTokens`, which also changes native compaction and Emergency Rollover and cannot default to zero for this extension alone; and an entirely empty Tail at 0, which would drop the `context_rollover` result that a continuing agent loop expects.
