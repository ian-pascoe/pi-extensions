# Read other sessions' Notes and History, never write them

Notes and History remain owned by one session branch, but `context_notes` and `context_history` accept a Search Scope (Branch by default, Lineage, Repository, or All) that reads other sessions. Reads never write: a session writes only its own journal, because a second session manager appending to another session's file would desynchronize that session's in-memory journal. A parent shares nothing by push; it reads a child's Lineage Notes live and may `copy` one into its own Notes as an unlinked snapshot, so Notes deleted with a Child Agent survive only where copied.

Other sessions are read as their latest branch, parsed from file contents without `SessionManager.open`, which can migrate and rewrite files; a partial final line from a live session is ignored. Pi groups sessions by working folder and records nothing about git, so each session records its repository's main worktree once, and older sessions are matched by resolving their recorded folder; sessions whose folder is gone and that lack the record appear only in the All scope. Search runs newest session first, pages with `next_offset`, and builds no index, consistent with deriving state from Pi sessions. The Note Index lists only the agent's own Notes.
